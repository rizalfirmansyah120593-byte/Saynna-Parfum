## Highlights

- **Scroll-driven storytelling** — botol parfum bergerak mengikuti scroll dengan GSAP ScrollTrigger.
- **Premium dark theme** — charcoal, espresso, dan aksen gold yang konsisten.
- **Responsive experience** — layout desktop dan mobile yang adaptif.
- **Scent profile** — top, heart, dan base notes ditampilkan dengan jelas.
- **Product catalog** — halaman katalog dengan keranjang dan total harga otomatis.
- **WhatsApp checkout** — pesanan dikirim ke WhatsApp dalam format siap konfirmasi.
- **SEO ready** — metadata, Open Graph, semantic HTML, dan Product structured data.

## Run Locally

```bash
git clone https://github.com/rizalfirmansyah120593-byte/Saynna-Parfum.git
cd Saynna-Parfum
python -m http.server 5500
```

Buka `http://localhost:5500` di browser. Katalog belanja tersedia di [`product.html`](./product.html).
